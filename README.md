# Acinetobacter-baumannii-OneHealth
Custom scripts in the manuscript.
This repository contains the custom Python and R scripts used in our study investigating the global cross-compartment dissemination and evolutionary dynamics of Acinetobacter baumannii across clinical, environmental, and animal interfaces. Specifically, the scripts cover reciprocal whole-genome ANI screening (`ANI_cross_compartment_filter.py`), high-resolution transmission pair identification via cgMLST (`cgMLST_cross_compartment_pairs.py`) and core-genome SNPs (`coreSNP_transmission_pairs.py`), spatiotemporal balanced subsampling of IC2 isolates (`IC2_balanced_subsampling.py`), and discrete-trait model selection and Bayesian ancestral state reconstruction (`BEAST2_ASR_transitions.R`). All analyses were implemented in Python (v3.9+ with `pandas` and `numpy`) and R (v4.3+ with `ape`, `treeio`, `tidytree`, `phytools`, and `dplyr`), and are distributed under the MIT License.
